# Prizm Connections
This is a port of [New York Times connections](https://www.nytimes.com/games/connections) for the Casio Prizm fx-cg50. It might work on other Prizm calculators but I haven't tested them. Some parts of the code were adapted from [PrizmWordle](https://www.cemetech.net/downloads/files/2233/x2570) by rickymat8.

All the games were gotten from [NYT-Connections-Answers](https://github.com/Eyefyre/NYT-Connections-Answers/tree/main) by Eyefyre.

## Features
- Play connections on a Casio Prizm calculator
- 831 total games
- Color coded groups (Green - Easiest, Yellow - Easy, Blue - Hard and Purple - Hardest)
- Button to reveal answers

## Controls
| Key | Action |
|------|--------|
| Arrow Keys | Move cursor |
| EXE | Select / Deselect |
| F2 | Deselect all |
| F5 | Submit answer |
| AC | Reset puzzle |
| 0 | Reveal answer |
| OPTN | View Stats |

## Installation
- Download Connections.g3a (No need to download the whole project)
- Connect your calculator to your computer via USB
- Copy the file into the calculator's storage memory
- Disconnect the calculator and launch the application from the main menu
